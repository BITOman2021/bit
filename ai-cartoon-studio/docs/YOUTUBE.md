# YouTube

The platform prepares everything (titles, description with real chapter timestamps, tags/hashtags, 1280×720 thumbnail with correct Arabic shaping,
SRT in primary/secondary/bilingual, a zip package). **Automatic upload is not implemented**: it needs a Google Cloud OAuth client and consent flow.
`GET /api/youtube/status` reports this honestly. Upload the package manually in YouTube Studio. For children's content set *Made for kids*.
Monetization depends on YouTube's policies and on owning rights to everything you publish (music, voices, characters).
