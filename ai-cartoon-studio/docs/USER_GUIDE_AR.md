# دليل المستخدم (العربية)
1. **أنشئ حساباً**. زر اللغة في أعلى الصفحة، وبجانبه المظهر الداكن/الفاتح. من **لوحة التحكم ← حالة المحركات** تعرف ما هو متاح في جهازك.
2. **المشاريع**: أنشئ مشروعاً؛ التعديلات تُحفظ تلقائياً مع سجل يمكن الاستعادة منه، ويمكن نسخ المشروع أو تصديره كملف zip.
3. **القصة**: اكتب الفكرة ← يُنشأ هيكل المشاهد (أو سيناريو مكتوب بـ Ollama) ← عدّله ← «تطبيق على المشروع» لملء الخط الزمني.
4. **الشخصيات**: املأ الملف، ارفع صورة مرجعية، يمكنك قفل الهوية، ثم ولّد ورقة الشخصية (وضعيات وتعبيرات، تحتاج ComfyUI). تعديل المظهر يطلب تأكيداً حفاظاً على الثبات.
5. **الصور** (تحتاج ComfyUI): اختر الشخصيات (يُحقن وصفها في كل صورة) والأسلوب والنسبة والجودة والإضاءة والكاميرا. أدوات الصور (تكبير، إزالة خلفية، تعديل) تعمل بدون GPU.
6. **الصوت**: اختر صوتاً، عاينه، ثم اعتمده واحفظه، وخصّص صوتاً لكل شخصية. لا يوجد استنساخ لأصوات أشخاص حقيقيين.
7. **المحرر**: لكل مشهد اختر الصورة/الفيديو والحوار والحركة والسرعة والتلاشي والترجمة (بلغتين) والنصوص؛ أضف موسيقى؛ «معاينة هذا المشهد»؛ ثم «تصدير الفيديو» (16:9 و9:16 و1:1 بدقة 720 أو 1080). يمتد المشهد تلقائياً ليغطي مدة الحوار.
8. **يوتيوب**: العنوان والوصف والوسوم والصورة المصغرة، ثم نزّل الحزمة وارفعها يدوياً.
9. **SAM KIDZ**: استورد الصور المرجعية لـ Bonnie وBro وSafsoof وSara (تُحفظ كما هي ومقفلة)، وأنشئ الحلقات وتابع حالتها.
تظهر الأخطاء باللون الأحمر مع السبب (مثل «ComfyUI غير متاح»)؛ لا يوجد نجاح وهمي.
