# User guide (English)
1. **Create an account** (language switch top-right; dark/light toggle next to it). Check **Dashboard → AI engine status** to see what is available on your setup.
2. **Projects**: create one; edits auto-save and keep a history you can restore; duplicate or export as zip.
3. **Story**: describe an idea → scene scaffold (or Ollama-written script) → edit → *Apply to project* to fill the timeline.
4. **Characters**: fill the profile, upload a reference, optionally lock identity, generate a sheet (poses/expressions, needs ComfyUI). Appearance edits ask for confirmation.
5. **Images** (ComfyUI needed): pick characters (their profile is injected), style, ratio, quality, lighting, camera. Image tools (upscale, remove background, edit) run on CPU.
6. **Voice**: choose a voice, preview, approve & save; assign a voice to each character. No cloning of real people.
7. **Editor**: per scene choose image/video, dialogue audio, motion, speed, fade, subtitles (two languages), text overlays; add music; *Preview this scene*; *Render video* (16:9, 9:16, 1:1; 720p/1080p). A scene is automatically at least as long as its dialogue.
8. **YouTube**: metadata, thumbnail, download the package, upload manually.
9. **SAM KIDZ**: import reference images for Bonnie, Bro, Safsoof, Sara (stored unchanged, locked), create episodes and track status.
Failures are shown in red with the reason (for example "ComfyUI not reachable"); nothing is faked.
