# دليل الأدوار والصلاحيات

تُفرض الصلاحيات **على الخادم في طبقة الخدمات** لكل قراءة وكتابة (وليس بإخفاء الأزرار فقط)، وتضاف إليها:

1. **نطاق العقارات:** `ALL` (كل العقارات) أو `RESTRICTED` (العقارات المحددة في `user_property_access`). كل استعلام
   يُقيَّد تلقائيًا بنطاق المستخدم، وأي وصول لسجل خارج النطاق يعيد "غير مسموح/غير موجود".
2. **المالك:** يرى فقط العقارات التي يملك فيها حصة سارية، وكشف حسابه فقط.
3. **المستأجر:** بوابة منفصلة؛ يرى وحدته وعقده ومدفوعاته وطلباته ومستنداته فقط.
4. **الفني:** يرى أوامر العمل المسندة إليه فقط.
5. **فصل المهام:** لا يمكن لمقدم طلب الاعتماد أن يعتمده بنفسه (ولا حتى المدير).
6. **البيانات الحساسة:** أرقام الهويات تظهر مقنّعة (`•••• 678`) ومستندات الهوية مخفية لمن لا يملك `tenant.sensitive`.
7. **سجل التدقيق:** قراءة فقط لمن يملك `audit.read`؛ لا يمكن لأحد تعديله (مشغل قاعدة بيانات).

## الأدوار الافتراضية

| الدور | المفتاح | الوصف المختصر |
|---|---|---|
| مدير النظام | ADMIN | كل الصلاحيات الإدارية (عدا بوابة المستأجر) |
| مالك العقارات | OWNER | عرض عقاراته وتقاريرها المالية وصيانتها ومستنداتها؛ لا تعديل |
| مدير العقارات | PROPERTY_MANAGER | تشغيل كامل للعقارات والعقود والمالية التشغيلية والاعتمادات؛ بلا إدارة مستخدمين أو دليل حسابات أو قيود يدوية |
| المحاسب | ACCOUNTANT | التحصيل والإلغاء والمصروفات والفواتير والقيود والتسويات؛ **لا يستطيع اعتماد** الطلبات ولا تعديل سجل التدقيق |
| مسؤول الصيانة | MAINTENANCE_MANAGER | الطلبات وأوامر العمل والأصول والموردين والمشتريات |
| موظف التحصيل | COLLECTOR | تسجيل التحصيلات وعرض المتأخرات؛ لا إلغاء ولا مصروفات |
| موظف التأجير | LEASING | المستأجرون (مع البيانات الحساسة) والعقود (مسودات وتجديد)؛ لا اعتماد |
| الفني | TECHNICIAN | أوامر العمل المسندة إليه فقط: البدء والإنجاز |
| المستأجر | TENANT | بوابة المستأجر فقط |
| المراجع المالي | AUDITOR | قراءة المالية والقيود والتقارير وسجل التدقيق؛ لا تعديل |

## الاعتمادات (Approvals)

| العملية | متى تحتاج اعتمادًا |
|---|---|
| مصروف / فاتورة مورد / أمر شراء | عند بلوغ `approval.expenseThreshold` (افتراضي 500 ر.ع.) |
| تقدير تكلفة أمر عمل | عند بلوغ `approval.workOrderThreshold` (افتراضي 200 ر.ع.) — لا يبدأ العمل قبله |
| رد/استقطاع تأمين، رد مبلغ زائد | دائمًا |
| تحديث بيانات اتصال من بوابة المستأجر | دائمًا |
| تفعيل العقد وإنهاؤه | يتطلبان صلاحية `lease.approve` مباشرة |
