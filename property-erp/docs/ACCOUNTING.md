# المحاسبة والدقة المالية

## سياسة المبالغ والتقريب

- كل الحسابات بعدد صحيح من **البيسة** (`bigint`، 1 ر.ع. = 1000 بيسة) — `src/lib/money.ts`. لا تُستخدم أرقام الفاصلة العائمة.
- التخزين `NUMERIC(18,3)`، والعرض بثلاث منازل عشرية.
- الإدخال: يُرفض أي مبلغ بأكثر من 3 منازل عشرية (لا تقريب صامت للمدخلات).
- التقريب للمبالغ المحسوبة (التناسب، الضريبة): **نصف للأعلى بعيدًا عن الصفر** إلى أقرب بيسة.
- التوزيع النسبي (نسب الملكية): طريقة **أكبر باقٍ** — مجموع الحصص يساوي المبلغ تمامًا.

## جدول الاستحقاقات

- الإيجار يُعرّف كإيجار شهري؛ كل استحقاق = الإيجار الشهري × عدد أشهر الفترة (شهري/ربع/نصف/سنوي)، مستحق مقدمًا.
- الفترات تُحسب دائمًا من تاريخ البداية الأصلي (لا انجراف عند بداية الشهر في يوم 31).
- الفترة الأخيرة الجزئية: أشهر كاملة + (أيام متبقية × الإيجار الشهري ÷ أيام ذلك الشهر) مقرّبة إلى البيسة.
- لكل استحقاق رقم فريد (`CHG-YYYY-NNNNNN`)، المبلغ الأصلي، المدفوع، المتبقي، الحالة.
- **قيمة العقد ≠ المستحق فعليًا:** الاستحقاقات المستقبلية لا تُحتسب مستحقة قبل تاريخها، والإيراد مؤرخ بتاريخ الاستحقاق.
- رسوم التأخير لا تُطبق آليًا أبدًا: تتطلب تفعيلًا في الإعدادات + نص في العقد + متأخرات تتجاوز فترة السماح + إضافة يدوية.

| العملية | المدين | الدائن |
|---|---|---|
| استحقاق إيجار/رسوم | ذمم المستأجرين 1200 | إيرادات الإيجار 4100 / الخدمات 4200 / التأخير 4300 / أخرى 4900 + ضريبة المخرجات 2300 |
| استحقاق تأمين | ذمم المستأجرين 1200 | تأمينات المستأجرين 2200 (**التزام وليس إيرادًا**) |
| تحصيل | النقدية 1100 / البنك | ذمم المستأجرين 1200 |
| إلغاء تحصيل | قيد عكسي كامل | |
| رد تأمين | تأمينات المستأجرين 2200 | النقدية/البنك |
| استقطاع من التأمين (معتمد) | تأمينات المستأجرين 2200 | استقطاعات من التأمينات 4400 |
| رد مبلغ زائد | ذمم المستأجرين 1200 | النقدية/البنك |
| مصروف مباشر | حساب الفئة (5xxx) أو الأصول الرأسمالية 1500/1510 + ضريبة المدخلات 1250 | النقدية/البنك |
| فاتورة مورد | حساب الفئة أو الأصل + ضريبة المدخلات | ذمم الموردين 2100 |
| دفعة مورد | ذمم الموردين 2100 | النقدية/البنك |
| إلغاء استحقاق / عقد منتهٍ مبكرًا | قيد عكسي للاستحقاق غير المدفوع | |

- الإيراد يُسجل **عند الاستحقاق** فقط؛ التحصيل يخفض الذمم فقط ← **لا يُحتسب الإيراد مرتين** عند إصدار الإيصال.
- الدفعة الزائدة تبقى رصيدًا دائنًا في ذمم المستأجر (غير مخصص) ويمكن تطبيقها لاحقًا أو ردها باعتماد.
- كل سطر قيد يحمل العقار والوحدة والمستأجر/المورد ← تقارير العقار والمالك متوازنة ومطابقة للدفتر.

## الضمانات المطبقة (شروط القبول)

| الشرط | كيف تحقق |
|---|---|
| أنواع عشرية دقيقة | `NUMERIC(18,3)` + بيسة صحيحة |
| فصل تاريخ الاستحقاق عن التحصيل | `dueDate` في الاستحقاق، `receivedDate` في الدفعة؛ القيود مؤرخة بكل منهما |
| دفع جزئي وتسويات واسترداد | التخصيص الجزئي، تطبيق الرصيد، الاسترداد المعتمد |
| منع التكرار | `idempotencyKey` فريد لكل دفعة (يُولّد عند عرض النموذج) + ترويسة `Idempotency-Key` في API |
| معاملة واحدة للترحيل | كل عملية مالية داخل `prisma.$transaction` |
| منع القيد غير المتوازن | تحقق في التطبيق + مشغل قيد مؤجل في PostgreSQL |
| لا تعديل صامت | مشغل يمنع تعديل/حذف القيود المرحّلة وسطورها |
| لا ترحيل للفاتورة مرتين | `sourceKey` فريد لكل قيد (`INVOICE:<id>`) + رقم فاتورة المورد فريد لكل مورد |
| التأمين ليس إيرادًا | حساب التزام 2200 |
| رأسمالي مقابل تشغيلي | فئات رأسمالية تُرحّل إلى حسابات أصول؛ الخيار صريح في النموذج |
| سجل لكل تعديل مالي | سجل تدقيق غير قابل للتعديل (من، متى، ماذا، قبل/بعد، IP) |
| التزامن | أقفال صفوف `FOR UPDATE` على الاستحقاقات والدفعات والتأمينات أثناء التخصيص |

## الضرائب

ضريبة القيمة المضافة في سلطنة عُمان قائمة، لكن انطباقها يختلف حسب النشاط (مثل التأجير السكني مقابل التجاري).
**النظام لا يطبق أي نسبة أو إعفاء تلقائيًا:** الضريبة معطلة افتراضيًا (`tax.enabled=false`)، ونسبة العقد صفر افتراضيًا،
وتدخل ضريبة فواتير الموردين يدويًا. يجب التحقق من الانطباق مع مستشار ضريبي وجهاز الضرائب قبل التفعيل.

## التقارير المحاسبية

ميزان المراجعة، قائمة الدخل، قائمة المركز المالي (مع أرباح الفترة غير المقفلة)، التدفق النقدي (حركة حسابات النقدية
والبنوك حسب المصدر)، حركة حساب، مقارنة الفترات — جميعها تُحسب من **القيود المرحّلة فقط**.
لم يُنفذ إقفال الفترات/السنة المالية آليًا (انظر STATUS.md).
