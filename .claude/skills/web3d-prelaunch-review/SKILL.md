# لا تنشر أول نسخة مباشرة

الأولوية نسخة محلية تُراجَع، وقرار النشر للمستخدم وحده. جهّز قائمة إطلاق:

1. **المحتوى والحقوق:** الأسماء، الأسعار، الصور، وسائل التواصل، شروط الخدمة.
2. **الحسابات والتكاليف:** من يملك النطاق والاستضافة؟ ما التجديدات؟ من معه صلاحية الدخول؟
3. **النماذج والبيانات:** إن جمع الموقع معلومات، وين تروح وكيف تُحمى؛ راجع المتطلبات القانونية المناسبة للبلد (لا تفترض).
4. **نسخة وشرح:** احفظ نسخة (git tag/branch) وحدد طريقة التحديث قبل أي إطلاق.

## قواعد صارمة
- لا تنفذ نشرًا أو حذفًا أو شراءً أو تغيير حساب إلا بطلب صريح ومعرفة المستخدم بالأثر.
- ارجع للتوثيق الرسمي لمنصة الاستضافة المختارة قبل خطوات تقنية محددة.

## قائمة «جاهزة للمراجعة»
- الهدف والمحتوى واضحان ومراجَعان
- الأزرار والروابط تعمل
- الصفحة مقروءة على الهاتف والكمبيوتر
- تجربة 3D مفيدة ولها بديل مناسب
- التغييرات والملفات مراجَعة بنفسك
- النشر أو الدفع خطوة منفصلة بقرار منك
