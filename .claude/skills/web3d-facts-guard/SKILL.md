# خلّي الحقائق عندك

اكتب وصفًا واضحًا للخدمة أو المنتجات. أي معلومة ناقصة تظهر كـ«بحاجة تأكيد» بدل أن تتحول لادعاء.

| النوع | مثال |
|-------|------|
| مؤكدة | «القطع مصنوعة يدويًا في دفعات صغيرة» (إذا فعلًا كذلك) |
| بحاجة تأكيد | «توصيل لكل الأردن» قبل التأكد من المناطق والتكلفة |
| الصور والملفات | استخدم صورًا تملك حقها؛ وإلا عناصر مؤقتة بعلامة واضحة |
| خاصة | لا تلصق كلمات مرور أو مفاتيح API أو بيانات زبائن حقيقية |

## البرومبت المرجعي
> استخدم المعلومات التالية فقط: [الحقائق المؤكدة]. هاي النقاط لسه بحاجة تأكيد: [القائمة]. اكتب نص الأقسام المطلوبة، وعلّم المعلومة الناقصة بكلمة «بحاجة تأكيد». لا تخترع شهادات أو أسعارًا أو عدد عملاء أو نتائج مبيعات. افصل اقتراحاتك عن النص الجاهز للنشر.

استبدل أي مثال تدريبي ببيانات المشروع الحقيقية بعد المراجعة.
