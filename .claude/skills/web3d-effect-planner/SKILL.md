# اختر التقنية حسب الحاجة

اشرح للمستخدم ماذا سيشوف الزائر، وقارن الخيارات **قبل** إضافة أي مكتبة:

| الخيار | الوصف | متى |
|--------|-------|-----|
| **A** | حركة بسيطة داخل الصفحة (CSS) | عمق بصري محدود؛ اسأل أولًا إن كانت CSS كافية |
| **B** | مجسم يقدر الزائر يلفّه | عند وجود ملف مجسم وطريقة عرض واضحة، **مع بديل ثابت للموبايل/الأجهزة الضعيفة** |
| **C** | مشهد تفاعلي كامل | يحتاج وقت تحميل وأداء ومراجعة أكبر؛ اعرف أثر المكتبة قبل اعتمادها |

## البرومبت المرجعي
> اقترح طريقة تضيف [وصف التأثير] إلى الصفحة. قارن خيار CSS بسيط مع مشهد 3D تفاعلي: الملفات المطلوبة، أثر كل خيار على الهاتف والتحميل، وطريقة توفير بديل بدون حركة. لا تثبّت مكتبات ولا تغيّر الصفحة الآن. أعطني توصية مع أسبابها وانتظر موافقتي.

## شروط قبول أي تأثير
- يخدم فهم المنتج أو استخدامه.
- المحتوى الأساسي واضح لو ما اشتغلت الحركة.
- بديل ثابت عند تقليل الحركة (`prefers-reduced-motion`) أو ضعف الجهاز.
- لا صوت ولا حركة مفاجئة بدون تحكم الزائر.
