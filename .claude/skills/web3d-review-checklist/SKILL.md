# اعمل جولة كأنك الزائر

فحص التجربة، مش الكود بس. افتح الصفحة فعليًا (Playwright/المتصفح إن توفر) وتأكد:

- [ ] تُفتح على الهاتف والكمبيوتر.
- [ ] القوائم والأزرار وروابط التواصل تعمل.
- [ ] كل قسم يشرح الخدمة/المنتج بوضوح.
- [ ] الخطوط، اتجاه العربية (RTL)، التباين، حجم الكتابة.
- [ ] لوحة المفاتيح للتنقل وموضع التركيز واضح.
- [ ] الحركة مع «تقليل الحركة» (`prefers-reduced-motion`).
- [ ] صور/مجسمات كبيرة لا تؤخر ظهور الصفحة.
- [ ] أدوات المطوّر/سجل الأخطاء بلا أخطاء.

## البرومبت المرجعي
> راجع المشروع مقابل `brief.md` وشروط القبول. افحص بنية المحتوى والروابط واتجاه العربية والتجاوب وإمكانية الاستخدام بلوحة المفاتيح والحركة. لكل نقطة اكتب: شو فحصت، النتيجة، والدليل. ميّز مراجعة الملفات عن تجربة فعلية بالمستعرض. لا تدّعي اختبار جهاز أو خدمة ما استخدمتها. أصلح المشاكل ضمن الموجز فقط، واذكر الباقي.

اطلب دليلًا: «اشتغل» لا تعني أن كل شيء اتجرّب؛ اذكر الصفحة والعرض والخطوات فعلًا.
