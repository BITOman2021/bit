# أصلح مشكلة واحدة

بدل «الموقع خربان» اطلب: اسم الصفحة/العنصر، العرض (مثلًا 390px)، السلوك المطلوب، السلوك الفعلي، خطوات التكرار.

## البرومبت المرجعي
> المشكلة في [الصفحة أو العنصر] على عرض [العرض]: المتوقع [السلوك المطلوب]، واللي بصير [السلوك الفعلي]. خطوات التكرار: [الخطوات]. افحص السبب وعدّل أقل قدر ممكن، وحافظ على الأقسام والنصوص الثانية. أعد نفس الفحص، واكتب الملفات التي غيّرتها والنتيجة وأي شي ما قدرت تجربه.

## بعد كل تعديل
1. اقرأ ملخص التغييرات وأسماء الملفات.
2. راجع الفروقات (`git diff`)، خصوصًا المحتوى والروابط.
3. افتح الصفحة وجرّب المشكلة المطلوبة.
4. إذا ظهر خطأ جديد، لقطة/ملاحظة وإصلاح على حدة.

لا تقبل حزمة أو تغييرًا كبيرًا لا يُفهم؛ اطلب تفسيرًا.
